# Invite-based self-registration with first-user-becomes-owner

New users register by consuming an invite link generated by a user with `MANAGE_USERS` permission. There is no open registration. The first user to register on a fresh server becomes the Owner (full admin), with no `ADMIN_PASSWORD` env var and no out-of-band bootstrap step.

This was chosen over admin-provisioned accounts (the operator creates accounts on behalf of users) because the app is meant to be non-technical-user-friendly and the operator does not want to manage accounts for friends. It was chosen over open registration because a public-facing server should not accept random signups. The invite pattern is familiar to anyone who has used Discord or Slack.

Email is optional and nullable from day one to allow password-reset-via-email later without a schema migration. Password reset without email is handled by the owner/admin resetting a user's password from the user management panel.
